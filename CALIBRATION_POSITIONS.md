# Sensor Calibration Positions - Visual Guide

This guide shows exactly how to position your club for each calibration step.

## Club Coordinate System

After calibration, the sensor data will be oriented to this club frame:

```
        Grip End (Handle)
              ↑
              | X-axis (up the shaft)
              |
              |
    Toe ←-----+----→ Heel
    (Y-axis)  |
              |
              | Z-axis (face normal, toward target)
              ↓
         Club Head
```

## Position 1: ADDRESS ⛳

**Purpose**: Establish the vertical (gravity) direction

```
     Person View (from behind)
     
           ||  ← Shaft (angled ~65°)
          //
         //
        //
    [======]  ← Club head on ground
    --------  ← Ground
    
    Side view:
    - Club head resting on or just above ground
    - Shaft at normal address angle
    - Face square to imaginary target line
```

**Key Points**:
- ✓ Normal golf posture
- ✓ Club head stable
- ✓ Face pointing forward (toward target)
- ✗ Don't lean shaft too far forward or back

---

## Position 2: TOE UP ☝️

**Purpose**: Identify the toe-heel axis (Y-axis)

```
     Side View
     
         ↑ (Toe points UP)
         |
    [===|===]  ← Club rotated 90°
         |
         ↓ (Heel points DOWN)
         
    The club is HORIZONTAL
    Face is PERPENDICULAR to ground
    (looking left or right, not up or down)
```

**Key Points**:
- ✓ Club held horizontally (parallel to ground)
- ✓ Toe edge pointing straight up
- ✓ Heel edge pointing straight down
- ✓ Face perpendicular to ground (vertical)
- ✗ Don't tilt club forward/backward

---

## Position 3: TOE DOWN 👇

**Purpose**: Confirm toe-heel axis direction

```
     Side View
     
         ↓ (Toe points DOWN)
         |
    [===|===]  ← Club rotated 90° opposite way
         |
         ↑ (Heel points UP)
         
    The club is HORIZONTAL
    Face is PERPENDICULAR to ground
    (opposite of Position 2)
```

**Key Points**:
- ✓ Club held horizontally (parallel to ground)
- ✓ Toe edge pointing straight down
- ✓ Heel edge pointing straight up
- ✓ Face perpendicular to ground (vertical)
- ✗ Should be exact opposite of Position 2

---

## Position 4: FACE UP 🔼

**Purpose**: Calibrate face normal (target direction)

```
     Top View
     
         Grip End
             |
             |
        [========]  ← Face pointing UP
                       (lying on its back)
     
     Side view from toe side:
     
     ---[    ]---
        ↑ Face pointing to sky
     
    The club is HORIZONTAL (flat)
    Grip and head at same height
```

**Key Points**:
- ✓ Club lying on its back
- ✓ Face pointing straight up to sky
- ✓ Grip and club head at same horizontal level
- ✓ Club is stable and level
- ✗ Don't let club tilt side to side

---

## Quick Reference Chart

| Position    | Club Orientation              | What Points Up     | Duration |
|-------------|-------------------------------|-------------------|----------|
| 1. Address  | Normal golf setup             | Grip (angled)     | 2 sec    |
| 2. Toe Up   | Horizontal, rotated 90°       | Toe edge          | 2 sec    |
| 3. Toe Down | Horizontal, rotated -90°      | Heel edge         | 2 sec    |
| 4. Face Up  | Flat on back                  | Club face         | 2 sec    |

## Tips for Holding Positions

### Stability
- Use both hands to hold club steady
- Brace arms against body if needed
- Take a deep breath and hold still
- Focus on a fixed point

### For Each Position
1. Get into position
2. Check orientation carefully
3. Click "Collect Data" button
4. Freeze and hold steady
5. Wait for "Position complete" message
6. Move to next position

### If Something Goes Wrong
- Position not held steady enough → Try again
- Club moved during collection → Repeat that position
- Data seems wrong → Start over with all positions

## Simple Calibration Alternative

If you're having trouble with all 4 positions, use **Simple Calibration**:

- Only requires **Position 1 (Address)**
- Takes just 30 seconds
- Less accurate but easier
- Good enough for basic use

See QUICKSTART_CALIBRATION.md for simple calibration steps.
